Expo Android / EAS Cloud Build

Build APK cho ung dung GomBill

Tai lieu thao tac tren Windows de tao file .apk cai truc tiep len dien thoai Android. Cach nay dung EAS cloud build, khong can cai Android Studio.

Khong chia se Supabase key cho nguoi khac

1. Chuan bi va build lan dau

Mo Command Prompt trong thu muc source. Thu muc dung phai co cac file package.json va app.config.js.

Kiem tra Node.js, npm va Corepack

node -v
npm -v
corepack --version
corepack enable
corepack install --global yarn@4.10.3

Cai thu vien va kiem tra source

yarn --version
yarn install
yarn typecheck
npx expo-doctor@latest
Ket qua mong doi: Yarn la 4.10.3 va Expo Doctor bao 18/18 checks passed.

Sua loi TypeScript neu gap lai

Neu lib/supabase.ts bao cachedClient is possibly undefined, doi dieu kien thanh: 

if (
  cachedClient &&
  cachedClient.url === supabaseUrl &&
  cachedClient.publishableKey === supabasePublishableKey
) {

Dang nhap va lien ket EAS

npm install --global eas-cli
eas login
eas whoami
eas build:configure

Khi EAS hoi platform, chon Android. EAS co the tu tao Git cuc bo. Day khong phai la GitHub va khong tai source cong khai.

Cau hinh tao APK thay vi AAB

Trong eas.json, bao dam profile preview co dang:

{
  "build": {
    "preview": {
      "distribution": "internal",
      "environment": "preview",
      "android": {
        "buildType": "apk"
      }
    }
  }
}
Quan trong: buildType: "apk" tao file cai truc tiep. Profile production mac dinh thuong tao .aab de dang Play Store.

2. Cau hinh Supabase tren EAS

Supabase luu tai khoan va du lieu thu chi. Source tai ve khong kem .env. Lay Project URL va publishable key trong Supabase Dashboard, cua so Connect. Khong dung service_role key. 

eas env:create --name EXPO_PUBLIC_SUPABASE_URL --value "DAN_URL_VAO_DAY" --environment preview --visibility plaintext

eas env:create --name EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY --value "DAN_KEY_VAO_DAY" --environment preview --visibility plaintext

eas env:list --environment preview
File .env.local do Supabase dua ra cho Next.js chi dung de lay gia tri. Ung dung Expo can dung ten bien bat dau bang EXPO_PUBLIC_ nhu cac lenh tren.

3. Sua loi Yarn runtime tren EAS

Neu log EAS bao khong tim thay .yarn/releases/yarn-4.10.3.cjs, file Yarn dang bi loai khoi goi upload.

Cap nhat .gitignore

Trong .gitignore, bao dam co cac dong:

.yarn/*
!.yarn/releases/
!.yarn/releases/**
!.yarn/patches/
!.yarn/patches/**

Tao .easignore

copy .gitignore .easignore

Mo .easignore va xoa dong .yarn/*. Sau do luu file va chay: 

git add .easignore
git commit -m "Include Yarn runtime in EAS archive"

4. Tao va tai APK

eas build --platform android --profile preview

Lan dau build, neu EAS hoi tao Android Keystore thi chon Y. EAS se luu keystore tren server va tai su dung cho cac ban build tiep theo.

  1. Cho den khi Terminal bao build thanh cong.
  2. Mo link EAS duoc in trong Terminal.
  3. Bam Download build de tai file .apk.
  4. Gui APK sang dien thoai va mo file de cai dat.
  5. Neu Android hoi quyen, cho phep cai ung dung tu trinh duyet hoac trinh quan ly file.

5. Build APK moi ve sau

Sau khi sua source, khong can lap lai cac buoc cai cong cu, tao keystore hay cau hinh Supabase. Chi can mo Terminal trong thu muc source va chay: 

yarn typecheck
npx expo-doctor@latest
git add .
git commit -m "Update app"
eas build --platform android --profile preview
Neu chi muon tao lai APK tu source hien tai ma khong co thay doi, chay rieng lenh eas build --platform android --profile preview.
