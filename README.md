# README

This app was built with ❤️ using [Draftbit](https://draftbit.com), [Expo](https://expo.dev), and [React Native](https://reactnative.dev).

## Project Notes

GomBill is a cross-platform shared ledger app for groups, members, venues, wallet balances, and transaction history. Data is currently stored as a local JSON ledger with import/export support, and Supabase auth is wired through public Expo environment variables when configured.

Android keyboard behavior is centralized in `lib/keyboard-controller.tsx`; APK builds force `adjustResize` so focused form inputs stay visible above the software keyboard.
